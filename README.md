# JoJo Juice Showcase & E-Commerce Web App

A modern, high-performance 3D interactive web showcase and e-commerce experience built for **JoJo Flavored Milk & Juice Drinks**.

## 🚀 Tech Stack

* **Framework**: Next.js 14+ (App Router)
* **Language**: TypeScript
* **Styling**: Tailwind CSS
* **Animations**: GSAP (ScrollTrigger), Framer Motion

---

## 🎨 Features & Highlights

* **3D Interactive Scroll Experience**: Smooth, scroll-driven visual showcase utilizing GSAP ScrollTrigger.
* **Verified Nutritional & Product Data**: Complete ingredient breakdown, health metrics, and manufacturer specifications (42.5 kcal/100ml, 1.0g protein, raw milk base, sweetener & allergen warnings).
* **Responsive UI Design**: Optimized desktop and mobile layouts using modern Fluent/glassmorphism design principles.
* **Clean TypeScript Integration**: Scoped type declarations eliminating ambient global namespace pollution.
